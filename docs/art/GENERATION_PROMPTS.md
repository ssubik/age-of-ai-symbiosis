# Machine Civilization v2 — Generation Prompt Set

Mode: OpenAI built-in image generation. Date: 2026-11-02.

All prompts shared this invariant block:

> Original stylized 3D game art for a 2:1 dimetric browser RTS. Graphite armor,
> brushed alloy, ceramic-white panels, cyan AI/power/data, amber construction and
> civic verification, coral hostile warning. Warm upper-left key light, cool
> ambient fill, readable silhouettes, full objects visible. No text, logos,
> cryptocurrency coins, copied characters, signatures or watermarks.

## AI economy key art

Wide 16:9 persistent robotic city in a Himalayan-inspired engineered valley.
Center a Command Core with cyan AI uplink, surrounded by Energy Generator, Alloy
Extractor, Compute Node, Unit Factory and Defense Turret. Humans and builder
robots physically construct the city while drones, an assault mech and a siege
walker move through it. Show the AI economy through power cables, cargo,
fabrication arms and data routes. Show blockchain only as amber ledger beacons
and verification nodes embedded into roads and the Core. Battlefield dominant;
no interface chrome or floating financial UI.

## Building family

Six separate buildings in a clean 3-by-2 board: stepped Command Core with cyan
uplink crown and amber proof nodes; horizontal Energy Generator; articulated
Alloy Extractor; protected Compute Node; broad Unit Factory with front bay and
gantry; tall rotating Defense Turret. Identical camera and lighting, subtle deck
plates, distinct rooflines and silhouettes, uncluttered charcoal background.

## Unit family

Eight separate full-body units in two rows: human systems engineer; compact
AI builder robot; triangular Scout Drone; broad biped Assault Mech; four-legged
Siege Walker; swept-wing Fighter; original heavy Iron Guardian exosuit; original
agile Aegis Valkyrie exosuit. Identical camera, down-right facing, clear contact
or hover shadows, role readability at 64–128 pixels, no superhero likenesses.

## Economy and weapons

Nine separate components in a 3-by-3 board: photovoltaic Energy turbine;
battery/grid relay; Alloy drill; alloy ingot and hauler; Compute server core;
amber ledger validation cube linked to four nodes; cyan pulse cannon; long rail
artillery; coral-capped missile pod. Make each mechanically plausible and use
blockchain only as provenance infrastructure, never monetary symbolism.

## Runtime alpha extraction

Each of the three family boards was edited non-destructively into an RGBA runtime
atlas. The extraction prompt required the original grid, geometry, camera,
lighting, scale and spacing to remain fixed while all pixels outside each object
and its immediate contact shadow became genuinely transparent. The economy atlas
received a second pass explicitly forbidding canvas-wide translucent matte or
haze after automated alpha inspection rejected the first extraction.
